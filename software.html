Kadi4Mat

Research data management • virtual research environment

Kadi4Mat is a generic, open-source virtual research environment for managing, exchanging, and working with research data. It combines repository capabilities with ELN-style workflows, analysis, and API-driven automation for reproducible research.

Website GitLab

Trixi.jl

Adaptive high-order simulations • Julia

Trixi.jl is an open-source numerical simulation framework for conservation laws in Julia. It focuses on adaptive high-order methods, accessibility for new users, and performant implementations for research and teaching.

Website GitHub

TrixiParticles.jl

Particle-based multiphysics simulation • Julia

TrixiParticles.jl is a high-performance framework for particle-based multiphysics simulation in Julia. It supports workflows such as WCSPH, TLSPH, DEM, fluid-structure interaction, complex geometries, and GPU-enabled computing.
